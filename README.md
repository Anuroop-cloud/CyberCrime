# CasePilot – CyberCrime Portal Workspace

> ⚠️ **IMPORTANT DIRECTORY NOTICE**  
> All commands must be run from inside the **`casepilot/`** directory.  
> Do **NOT** run `docker compose`, `npm`, or `npx prisma` from this outer directory.

### Quick Start:
```bash
cd casepilot
docker compose up -d
npm install
npm run db:migrate
npm run db:seed
npm run dev
```

See [`casepilot/README.md`](./casepilot/README.md) for full instructions and architecture details.
